# 日記# 聖黒竜の槍

【14日目】範囲攻撃武器の聖黒竜の槍をできるだけ楽に作る

投稿日 2023/04/22最終更新日 2023/04/22

2023年4月22日

今日はドロップ率3倍デー！

色々やりたいんだけど、とりあえず通常攻撃が範囲攻撃になる聖黒竜の槍を作る。
聖黒竜の槍の素材は盗めるのも多いので、別に3倍デーじゃなくても効率は悪くないと思うが、出来るだけ楽に作りたいので3倍デーで作った。

結論だけ言えばドロップ率3倍×デュアルトレジャー×盗みを使って5時間10分くらいで作ることが出来た。

作成は街の工房内からできる。

必要な素材の確認

簡単に言うと、
聖黒竜の槍を作る為に獅子王刀・牙簾が。

獅子王刀・牙簾を作るために真・竜王斬魔剣が。

真・竜王斬魔剣を作るために竜王斬魔剣が。

竜王斬魔剣を作るために各色赤・緑・黒のガイアブレード。
また先ほどの真・竜王斬魔剣を作るために青のガイアブレードが。
要するに赤・緑・黒・青のガイアブレードが必要。

各色のガイアブレードを作るために各色のドラゴンクローを作る。

という感じ。

ちょっとめんどくさそうなので、3倍デーでどれくらいかかるかやってみる。
作ってる最中はずっと以下の通りのステータスや装備。

バリゲットンを使う時は初期に配布されたチョコット装備でINTを1にしている。

素材を集める　～各色のガイアブレードまで～

ここで必要になる素材は

  1. 戦士の剣×4

  2. 赤系

    1. リュウの赤角×15

    2. 炎竜のヒレ×3

    3. 炎竜の片角×3

    4. 獄竜の強角×1

  3. 緑系

    1. リュウの緑角×15

    2. 古竜のヒレ×3

    3. 古竜の片角×3

    4. 蛮竜の背板×1

  4. 黒系

    1. リュウの黒角×15

    2. 闇竜のヒレ×3

    3. 闇竜の片角×3

    4. 淵竜の長角×1

  5. 青系

    1. リュウの青角×15

    2. 水竜のヒレ×3

    3. 水竜の片角×3

    4. 霞竜の潤角×1

戦士の剣は道具屋の娘から購入が可能なので、購入。
あとの素材は全部盗めるので、バリゲットンをセットし、INTを出来るだけ低くして盗む！

スムーズな素材の集め方として、

  1. リュウの〇角を各色の各色のリュウから集める

  2. 〇竜の片角と〇竜のヒレを各色の竜から集める

  3. ブレードに必要な各素材を各色の龍から集める

がいいと思う。
ここでは、リュウは一番小さい雑魚敵で、竜が中ボス、龍がヴァルカン系のボスとして表現する。

例えば、赤のブレードを作るなら

  1. リトルブレイズからリュウの赤角を15個集める

  2. トリアケラスから炎竜の片角×3と炎竜のヒレ×3を集める

  3. ボルドヴァルカンから獄竜の強角×1を集める

  4. それぞれを合成してブレードを作る

という感じ。

盗めばかかる時間は一色あたり15分も無いと思う。
部屋を作り直すと敵キャラがリポップしてるので、そうすればもっと早いかも。

それぞれの場所は

リュウと竜の場合
赤:ヴォルケ、緑:グランガン、黒:レイコール4Fボス部屋（5階から行くと早い）、青:グランガン

龍の場合
赤:ヴォルケ、緑:グランガン、黒:夢界、青:グランガン

にいる。

黒の龍に合う為に

個人的にちょっとやることが多かったのでまとめる。

そもそも、ある程度めんどくさいので、こいつの素材淵竜の長角×1だけバザーで買っちゃうのは全然あり。

黒の龍はブラキラボラスってやつなんだけど、こいつは夢界っていうところにいる。

夢界っていうのは夢見のキャップ＆夢見のパジャマを着て夢見のハンマーを神殿入口の太った兵士に渡すと行けるところ。
装備＆道具はポドックのモリッコから自分で作れるんだけど、バザーで3ptとかでも売ってるから買っても全然いいと思う。
私は買った。

そんで、夢界に行く前にレイコールのクエスト「悪夢の原因を突き止めろ」を受けないといけない。
レイコールのクエストが一切進んでない人は以下の通りにやれば大丈夫。

まず、1階の入口にいるフードの男から水汲みのクエストを受ける。

水汲み場所は、1Fに入ってずっと分岐を右に行ってれば着く。

水を汲んで報告したら、また話しかけてレイコール5Fのクリムゾンデモンを倒しに行く。
6Fから逆走するのが早い。

このクエストをクリアしたら2Fへ行く。

2Fに入ったら左に行って、下の画像みたいな分岐の場所まで行く。

この分岐を右上に行って、直ぐ右の分岐を曲がればフードの男がいる一本道になっている。

2Fのフードの男と「嫌な夢について」を話して「悪夢の原因を突き止めろ」を受注。

クエストを受けたら神殿前の兵士から夢界へ行く。

重ねてになるが、夢見装備と夢見ハンマーはバザーで買えるので安ければ買っていいと思う。

とりあえず夢界に入ったら道なりに進んで、レイコールみたいな場所まで来たら左にある牢屋に入る。

この意味深な緑のワープからウィステラに向かい、ウィステラから中央広場に。

広場から右上に向かう。

右上にフードの男がいるので、そいつに話しかけてようやく黒い龍ブラキラボラスへ

青い竜と龍に会う為に

なんかこちらもある程度ややこしかったのでまとめる。

青い竜に会うにはこのグランガンの分岐路を左下からいける霧道を通ればいけるのだが、どうしても無限ループになってしまう。

どうもこの霧道を通るには緑界の統治者ベルデダーマのクエストをクリアしとかなきゃいけないっぽい。

最後のクエスト以外はロードマップでクリアしてるはず。

最後のクエストはドラゴンエッグを取り返してくるってやつなので、緑の龍からドラゴンエッグだけ盗むorドロップさせてクエストをクリアする。

クリアしたらもう一回ベルデダーマに話しかけて霧道の結界を解いてもらう。
これで青の竜達に会える。

ここまで1時間くらいで終わるかと思ったけど、開通とかもあったから2時間弱はかかってる。

素材を集める　～真・竜王斬魔剣まで～

ここで必要な素材は
巨竜の逆鱗×3
だけ。

とりあえず、作った赤緑黒のガイアブレードを合成して竜王斬魔剣に。

巨竜の逆鱗×3はブラキルネウスから落ちる。
ブラキルネウスは魔断層にいるので魔断層へ。

EASYでいいと思われる。

とりあえず目当てのブラキルネウスを倒したいんだけど、少し進めないといけない。

基本一本道らしいので、適当にアンビシャスからクエストを受けつつ進めていく。

最初のクエストは条件数雑魚敵を倒した後にトラップキーパーを倒す。
謎の連撃耐性があるので殴って倒す。

そこからずっと進めばお目当てのブラキルネウスがいる。

盗めないらしいので、ドロップで逆鱗を3つ集めていく。
ここでドロップ率3倍デーが輝く。

大体30分もかからないくらいで集まった。

これで真・竜王斬魔剣へ。

素材を集める　～獅子王刀・牙簾まで～

ここで必要な素材は
獅子の朱爪×15
ブラックオニキス×2
どちらもアマガハラで手に入る。

こちらもEASYでおｋ。

獅子の朱爪は獅子王のいとこにいる取り巻きから出る。
盗めない

ブラックオニキスは天狗から出る。
盗めない

こいつ連撃効かないから好きじゃないんだけど、しかたないね。
通常攻撃だと3分くらいかかったので、コソバーンに切り替えて倒して集めた。

コソバーンなら大体1分もかからないくらいで倒せる。

獅子の朱爪とブラックオニキス合わせて大体30分くらいで集めることができた。

これで獅子王刀・牙簾完成。

素材を集める　～聖黒竜の槍まで～

ここで必要なのは
折れた黒金槍×30
エーテル火金属×50
どちらも職業協会系のミッションから手に入る

まず折れた黒金槍を手に入れる為に魔術ギルドへ。

ここで救助対象の偽物として沸く白い骸骨が取り巻きの「毒術の魔術師」から盗む。

というか、これ30本って正気か？　ってくらい効率悪い。

一応盗むだけじゃなくドロップもある。槍は床の色と同化してるので注意。

また、捕まってるキャラがいる部屋は固定。
左下の2つと左上の2つがニンジャ。
のこりの下の扉がプリースト。
のこりの上の扉がホーリーナイト。

ドロップ3倍デー×盗み×デュアルトレジャーを使って1時間30分弱で30本集まった。

次はエーテル火金属を50個集める。

こちらも職業協会で幻惑の森

エーテル火金属を盗める＆落とすのがドクノハナというやつ。

なんか適当に回ってれば40分ぐらいで50個集めることが出来た。

完成

これでようやく目的の聖黒竜の槍が完成。

なんでこの武器を作りたかったかっていうと、ユニオンで虹装備の一部を作りたかったから。

といっても

23個しかユニオンコインはないのであまり期待はできなさそう。

本当はドロップ率3倍でユニオンコイン無くなるまでやろうと思ってたんだけど、もうあと1時間しかないので今日はこれで終わり。

お疲れ様でした。

シーフでメタルビビリの間に行ったら倍率66倍でLv50→Lv90になった。
