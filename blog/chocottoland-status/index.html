# 日記# ステータス

【番外編】初心者が知っておきたいステータスについて

投稿日 2023/03/30最終更新日 2023/03/30

2023年3月30日

はじめに

ニンジャへの転職する際にステ振りやスキル振りを考えて色々調べてたら知らない単語とか仕様が多すぎたので初心者が知っておきたいステータス関係のことをまとめる。

注意事項
・全て検証したわけでなくネットの情報をまとめたものです。
・バージョンにより仕様が変わることがあります。
・簡潔な結論は目次からまとめを参照。

ステータス

ステータスは画面のように沢山の要素で出来ている。
POWとATKの違いってなんやねんとか色々ツッコミたいところはあるが、一つずつ見ていこう。

ステータスの基礎知識

  • ステータスは職業毎の初期値+149まで振り分けることができる。
    ※昔はステータス上限解放が必要だったが今は不要
    昔は+99までだった気がするがなんか、開放されていた。

  • キャラクターのレベルは99が上限。
    ※こちらも昔はレベル上限解放が必要だったが今は不要

  • ステータスポイントはLv80までは+3。それ以降は+1ポイント貰える。

  • 初期ステータスは職業により若干HP/SP/各ステータスが異なる。
    そのため、上画面のシーフだとSPDは149+3=152まで素で上げることができる。

  • LCK等の合計値はキャラ列と装備列の値を足したものになる。
    そのため、上画面のシーフだとLUKは2+10=12になる。

各種ステータス上昇要素の説明

ステータスが上がるときはどういう時なのかを説明。

  • 素のステータス
    普通に割り振るステータスのこと。
    転職時の有料パラメータ付与もこのステータスの扱い。
    HP・SP・チョコビタ等はこの素ステータスのみを参照して計算される。

  • 装備

    装備に表記されているステータスの値のこと。

  • セット装備

    セット装備対象の装備を必要数装備したときに発動するステータス上昇値のこと。

  • ヘアメイク

    なんか髪型を変えるときに有料ポイントCPを使って+2までステータスを上げられるらしい。
    髪型自体が600CPぐらいするし素ステータス扱いではないので実はそんなに安くない？

  • アバター



    hangeにあるアバター着せ替え要素を使ったステータス上昇方法。
    【】内に書いてある数値がそのまま適応される。
    チョコットランドに対応したアバターガチャを引くことで手に入れることが出来る。

  • ヌシステ


ペットに付けることが出来る装備のヌシステジュエルでステータスを上げる方法。
ペットが召喚されている間のみ適応される。
移動しないペットとかがいるらしいので、ステータス上昇目的ならそういうのにつけて攻撃されないところに放置するのがいいのかな？

上昇系スキル

スキルによって上昇するステータス値のこと。

チョコビタやリキッド系

チョコビタは素のステータスに対応した計算が行われるが、リキッド系はかなり複雑な計算なので説明を省く。（というよりややこしすぎて理解したくない）

バフ/ドーピングの順番

このチョコットランドではバフのことをドーピング、略してドピというらしいので、これからはドピという言葉を使う。

ドピの計算式的にドピしたステータスを更にドピするという行為が出来るので、出来るだけ効率のいい順番でドピをしたい。

しかし初心者な我々はリキッド系とチョコビタによるドピしか見込めないしそれしかわからない。
基本的にどっちも使うならチョコビタ→リキッド系の順で使うといいらしい。

もしアバタ―やヌシステを持ってたら調べてその順番でドピするのが効率がいい。

各種ステータスパラメータの説明

ここら辺はかなり細かいが理解しといて損はないので理解した方がいい。

  • POW
    ATKの上昇要素になる値。

  • INT
    魔法スキルの威力・回復力・持続時間やMAT・MDFに関係してくる。
    素ステータスのINTのみSPの最大量や座った時のSPの回復力に関係する。

  • SPD
    MOVや攻撃速度、スキルによっては射程・範囲・発動速度に関係。

  • VIT
    DEFの上昇要素になる値。
    素ステータスのVITのみHPの最大値や座った時のHPの回復力に関係する。

  • LUK
    いわゆる運。初心者にとって一番理解が大事だと思う。
    クリティカル発生率や回避に関係。即死系や盗みスキルの計算にも使われる。
    クリティカル発生率＝LUK％(ただし上限はLUK90の90％)
    回避発生率は計算式は所説あるが、

    • LUK100で25％
    • LUK150で50％
    • LUK200で75％
    • LUK230で限界値の90％

    と言われている。
    そのため、目指すべき理想のLUKは230となる。
    現在であればLUK150までステータスを振れるはずなので、従来よりかなり序盤でもLUK型を作るのは楽になっているのではないだろうか。

  • HP
    HPはレベル・素パラメータのVIT値・その他アバタ―や装備セット等でも上がる。
    VITを1上げる毎にHPが40上がるらしいが、検証はしていない。

  • SP
    SPはレベル・素パラメータのINT値・その他アバタ―や装備セット等でも上がる。
    こちらもINTを1上げる毎にSPが40上がるらしい。

  • ATK
    いわゆる物理攻撃力のこと。物理攻撃スキル等にも関与してくる。
    ATK補正合計とPOW×3の合計がこの値になる。

  • DEF
    いわゆる物理防御力のこと。
    DEF補正合計とVIT×2の合計がこの値になる。

  • MAT
    いわゆる魔法攻撃力のこと。
    MAT補正合計とINT×2の合計がこの値になる
    ただし、実際に使われる魔法攻撃力計算式はこのMATとは別らしいので要検索。

  • MDF
    いわゆる魔法防御力のこと。
    MDF補正合計とINT×15の合計がこの値になる。

  • EXP
    いわゆる経験値倍率のこと。
    上の画像ではアニバーサリーイベントで2倍になっている。

  • MOV
    いわゆるキャラの移動速度のこと。
    MOV補正合計とSPD-1の合計がこの値になる。

  • DRN
    いわゆるドレイン力のこと。
    なんか、通常攻撃するとHPを吸い取れるらしい。
    回復量＝(POW＋INT＋LUK)÷(1＋SPD÷10)×DRN
    のため、DRNが1でもないと発動しない。

  • HPR/SPR
    いわゆる自動回復力    のこと。
    最大HP/SP × HPR/SPR％を4秒毎に回復するらしい。

  • PET
    いわゆるペット捕獲成功率のこと。
    捕獲率＝対象の元の捕獲率+装備+アバター
    で計算される。

まとめ

  • 現在のステ振り限界値は150＆今は上限解放が不要なので昔のステ振り記事は参考にならないことが多い。

  • 物理攻撃力はATKを見ればよくて、3ATK=1POWで換算できるのでもし8ATK上昇と3POWの上昇で迷ったら3POWを取った方が攻撃力は上がるはず。物理防御力はDEFを見ればいい。2DEF=1VIT。

  • 魔法攻撃力はだいたいMAT。2MAT=1INTだが、実際の魔法攻撃力に使われるのはMATとは別の計算式らしい。

  • 魔法防御力はMDF。15MDF=1INTなので、14MDF上昇<1INT上昇の価値がある。

  • また、INTは魔法攻撃力も魔法防御力もSP最大値もあがるし、VITはHP最大値が上がる。

  • 最大HP/最大SP/チョコビタが参照する値は純粋に割り振った素のステータス。

  • 移動速度を見たいときはSPDじゃなくMOV

とりあえずここら辺が分かってればステータス初心者は脱却できたのではないだろうか。
